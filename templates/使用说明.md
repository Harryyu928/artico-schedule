# 数据导入模板使用说明

## 📥 一键导入数据

### 第一步：下载模板

在 `templates/` 文件夹中有以下模板：

| 文件名 | 用途 | 必填字段 |
|--------|------|----------|
| 学生导入模板.csv | 批量添加学生 | 学号、姓名、专业方向、申请国家 |
| 导师导入模板.csv | 批量添加导师 | 工号、姓名、类型、可教授课程 |
| 课程导入模板.csv | 批量添加课程 | 课程编号、课程名称、课程类型、课程分类 |

### 第二步：填写数据

#### 用 Excel 打开模板

1. 右键点击 `.csv` 文件
2. 选择"打开方式" → "Microsoft Excel"
3. 按照表头填写数据
4. 保存文件（选择"是"保持CSV格式）

### 第三步：上传导入

1. 访问系统管理页面
2. 点击"数据导入"
3. 选择要导入的类型（学生/导师/课程）
4. 选择填好的 CSV 文件
5. 点击"开始导入"
6. 等待导入完成，查看结果

## ⚠️ 注意事项

### 格式要求

1. **文件格式**：必须是 `.csv` 格式
2. **编码格式**：UTF-8（推荐）或 GBK
3. **表头**：第一行是表头，不能删除或修改
4. **空行**：不要有空行
5. **特殊字符**：如果内容包含逗号，需要用引号包裹

### 常见错误

| 错误 | 原因 | 解决方法 |
|------|------|----------|
| 导入失败 | 文件格式不对 | 确保是CSV格式 |
| 部分数据丢失 | 编码问题 | 用记事本打开，另存为UTF-8格式 |
| 字段错误 | 表头被修改 | 重新下载模板 |
| 重复数据 | 学号/工号已存在 | 检查是否有重复 |

## 📝 在线填写（替代方案）

如果没有 Excel，可以：

1. 用记事本打开模板
2. 按照格式填写，每行一条数据
3. 字段之间用逗号分隔
4. 保存为 `.csv` 文件

示例：
```
学号,姓名,专业方向,申请国家,当前阶段,总课时
2024001,张三,游戏设计,美国,基础阶段,100
2024002,李四,游戏美术,英国,项目阶段,150
```
