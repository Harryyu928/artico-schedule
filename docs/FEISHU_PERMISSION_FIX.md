# 飞书多维表格权限配置（已验证）

## 问题现象
调用飞书API写入多维表格时返回错误码 91403 (Forbidden)

## 根本原因
多维表格未授权给飞书应用

## ✅ 正确解决方法

### 步骤：

1. **打开多维表格**
   - 访问：https://feishu.cn/base/HbztbPxc1a8wT8s47FIcgM9annc

2. **添加文档应用**
   - 点击右上角 **「···」** 菜单（或「更多」）
   - 选择 **「添加文档应用」**（⚠️ 不是「添加协作者」）
   
3. **搜索并添加应用**
   - 搜索应用名称或应用ID：`cli_a94e5f1e32bb5cd1`
   - 点击添加

4. **验证**
   - 添加成功后，执行：`npx tsx scripts/feishu-diagnose.ts`
   - 如果返回成功，即可执行完整导入

---

## 注意事项

- 「添加协作者」是给人用的，「添加文档应用」是给应用用的
- 需要对每个要写入的表格都执行此操作（导师表、学生表、上课记录表）
- 如果找不到「添加文档应用」选项，可能需要在飞书管理后台先启用相关功能
