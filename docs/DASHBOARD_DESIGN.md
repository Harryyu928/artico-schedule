# 角色仪表盘设计对比

## 设计原则

**核心理念：每个角色只看自己关心的内容**

```
┌─────────────────────────────────────────────────────────────────┐
│                    角色仪表盘设计理念                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   不同角色 = 不同职责 = 不同关注点 = 不同仪表盘                    │
│                                                                 │
│   管理员     → 全局视角，关注系统整体运营                          │
│   规划顾问   → 学生视角，关注签约学生的服务                        │
│   导师       → 教学视角，关注课程安排和学生进度                     │
│   学生       → 学习视角，关注个人学习进度                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 核心差异对比表

| 维度 | 管理员 | 规划顾问 | 全职导师 | 兼职导师 | 学生 |
|------|--------|----------|----------|----------|------|
| **视角** | 全局 | 学生管理 | 教学管理 | 简化教学 | 个人学习 |
| **数据范围** | 全系统 | 签约学生 | 自己的学生 | 自己的课程 | 自己的信息 |
| **统计卡片** | 6个 | 4个 | 4个 | 3个 | 4个 |
| **快捷操作** | 6个 | 5个 | 5个 | 3个 | 5个 |
| **今日待办** | 系统健康 | 选课指导/预约 | 今日课程 | 今日课程 | 今日课程 |
| **进度展示** | 无 | 学生进度列表 | 学生进度列表 | 无 | 个人进度 |
| **管理功能** | 全部管理 | 学生管理 | 无 | 无 | 无 |

## 权限分层示意

```
权限等级（从高到低）：

管理员（顾问主管）
    │  全系统数据访问
    │  用户管理、系统设置
    │  数据统计、报表导出
    ▼
规划顾问
    │  签约学生数据访问
    │  选课单管理、时间预留
    │  学生进度跟踪
    ▼
全职导师
    │  自己学生的数据
    │  课程安排、上课记录
    │  课时统计
    ▼
兼职导师
    │  简化版功能
    │  仅课程相关
    │  较少课时管理
    ▼
学生
    │  仅个人数据
    │  学习进度、课程表
    │  无管理功能
```

## 技术实现

### 后端 API 根据角色返回不同数据

```typescript
// src/app/api/dashboard/route.ts

switch (role) {
  case '管理员':
    return await getAdminDashboard(user);     // 全局统计
  case '规划顾问':
    return await getConsultantDashboard(user); // 签约学生
  case '全职导师':
  case '兼职导师':
    return await getTeacherDashboard(user);    // 课程和课时
  case '学生':
    return await getStudentDashboard(user);    // 个人进度
}
```

### 前端根据角色渲染不同组件

```typescript
// src/components/dashboard/role-dashboard.tsx

switch (data?.role) {
  case '管理员':
    return <AdminDashboardContent data={data} />;
  case '规划顾问':
    return <ConsultantDashboardContent data={data} />;
  case '全职导师':
  case '兼职导师':
    return <TeacherDashboardContent data={data} />;
  case '学生':
    return <StudentDashboardContent data={data} />;
}
```

## 总结

**不一样！每个角色的仪表盘完全不同：**

| 角色 | 核心关注 | 数据范围 | 功能复杂度 |
|------|----------|----------|-----------|
| 管理员 | 系统运营 | 全局 | ★★★★★ |
| 规划顾问 | 学生服务 | 签约学生 | ★★★★ |
| 全职导师 | 教学安排 | 自己的学生 | ★★★ |
| 兼职导师 | 课程授课 | 自己的课程 | ★★ |
| 学生 | 学习进度 | 个人 | ★ |

这种设计的核心原则是：**让每个人只看到与自己相关的内容，减少信息干扰，提高工作效率。**
