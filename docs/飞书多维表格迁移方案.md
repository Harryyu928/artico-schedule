## 二、新多维表格设计

### 2.1 表结构概览

新系统采用 **6张核心表**：

```
┌─────────────────────────────────────────────────────────────┐
│                    新多维表格架构                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  📊 学生表 (students)                                        │
│     └── 学生基本信息、课时、状态                              │
│                                                             │
│  👨‍🏫 导师表 (teachers)                                       │
│     └── 导师信息、合作状态、收款信息                          │
│                                                             │
│  📝 上课记录表 (class_records)                               │
│     └── 每次上课的详细记录                                   │
│                                                             │
│  📋 选课单表 (course_selection_forms)                        │
│     └── 课程安排单据                                         │
│                                                             │
│  📄 合同表 (contracts)                                       │
│     └── 学生合同信息                                         │
│                                                             │
│  👔 顾问表 (consultants)                                     │
│     └── 升学顾问信息                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五、数据迁移步骤

### 5.1 准备阶段

1. **创建新多维表格**
   - 在飞书中创建新的多维表格应用
   - 按上述字段设计创建6张表
   - 配置字段类型和选项

2. **记录表格ID**
   - 获取新多维表格的 app_token
   - 记录每张表的 table_id

### 5.2 迁移顺序

按依赖关系迁移，确保外键关联正确：

```
1. 顾问表 (consultants) → 无依赖，先迁移
       ↓
2. 导师表 (teachers) → 无依赖，先迁移
       ↓
3. 学生表 (students) → 依赖顾问、导师
       ↓
4. 合同表 (contracts) → 依赖学生
       ↓
5. 选课单表 (course_selection_forms) → 依赖学生、顾问
       ↓
6. 上课记录表 (class_records) → 依赖学生、导师、顾问
```

### 5.3 数据清洗规则
