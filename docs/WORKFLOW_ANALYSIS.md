## 三、发现的问题

### 3.1 🔴 严重问题

#### 问题1: 缺少"选课指导课"环节

**现状**: 学生入学后直接进入"选课规划"阶段，缺少规划顾问与学生的一对一选课指导环节。

**业务影响**: 
- 学生不了解课程体系，选课方向不明确
- 规划顾问无法评估学生实际需求
- 时间表填写缺少指导，导致排课困难

**建议**: 在"入学登记"和"选课规划"之间增加"选课指导"阶段

#### 问题2: 缺少"课程进度跟踪"工作流

**现状**: `course_progress` 工作流在schema中定义但未实现。

**业务影响**:
- 无法跟踪学生长期学习进度
- 选课单进度无法自动更新
- 导师无法了解学生学习阶段

**建议**: 实现 `course_progress` 工作流

#### 问题3: 缺少"申请跟踪"工作流

**现状**: `application_tracking` 工作流在schema中定义但未实现。

**业务影响**:
- 无法跟踪学生申请进度
- 申请截止日期无法提醒
- 录取结果无法记录

**建议**: 实现 `application_tracking` 工作流

### 3.2 🟡 中等问题

#### 问题4: 角色映射不一致

**现状**: 
- 系统角色: 管理员(顾问主管)、规划顾问、全职导师、兼职导师、学生
- 任务角色: 管理员、全职导师

**影响**:
- 规划顾问职责不清晰
- 任务分配不准确
- 权限控制困难

**建议**: 调整任务分配，明确规划顾问职责

#### 问题5: "开始上课"阶段太简单

**现状**: 只有1个任务"开始第一节课"

**影响**:
- 无法跟踪后续课程
- 上课记录填写缺少触发
- 进度更新缺少机制

**建议**: 扩展为完整的课程跟踪流程

### 3.3 🟢 轻微问题

| 问题 | 说明 | 建议 |
|------|------|------|
| 任务描述简单 | 缺少操作指引 | 添加详细说明和跳转链接 |
| 阶段预估时间未展示 | `estimatedDays` 字段存在但未使用 | 前端展示预估时间 |
| 缺少自动推进机制 | 阶段完成后需手动推进下一阶段 | 添加自动推进逻辑 |
| 缺少超时提醒 | 任务超时无提醒 | 添加超时提醒功能 |

## 四、角色职责分析

### 4.1 系统角色定义

```
权限层级: 管理员(顾问主管) > 规划顾问 > 全职导师 > 兼职导师
```

| 角色 | 职责 | 对应系统角色 |
|------|------|--------------|
| 顾问主管 | 系统管理、数据分析、财务审批 | 管理员 |
| 规划顾问 | 学生管理、选课指导、进度跟踪 | 规划顾问 |
| 全职导师 | 授课、课程规划、上课记录 | 全职导师 |
| 兼职导师 | 授课、上课记录 | 兼职导师 |
| 学生 | 填写时间表、查看进度、签字确认 | 学生 |

### 4.2 任务分配建议

| 任务 | 当前角色 | 建议角色 | 理由 |
|------|----------|----------|------|
| 录入学生基本信息 | 管理员 | **规划顾问** | 规划顾问负责学生管理 |
| 确认缴费信息 | 管理员 | 管理员 | ✅ 正确，涉及财务 |
| 分配规划顾问 | 管理员 | 管理员 | ✅ 正确 |
| 选课指导课 | - | **规划顾问** | **新增任务** |
| 创建选课单 | 管理员 | **规划顾问** | 规划顾问负责选课指导 |
| 添加目标院校 | 管理员 | **规划顾问** | 规划顾问了解学生需求 |
| 规划课程明细 | 全职导师 | 全职导师 | ✅ 正确 |
| 设置学生可用时间 | 管理员 | **学生/规划顾问** | 学生填写，顾问可协助 |
| 设置导师可用时间 | 全职导师 | 全职导师 | ✅ 正确 |
| 执行自动排课 | 管理员 | 管理员 | ✅ 正确 |
| 确认排课结果 | 管理员 | **规划顾问** | 顾问负责通知学生 |
| 开始第一节课 | 全职导师 | 全职导师 | ✅ 正确 |
| 填写上课记录 | - | **导师** | **新增任务** |
| 更新选课单进度 | - | **系统自动** | **新增任务** |

## 五、改进方案

### 5.1 优化后的学生入学流程

```
阶段0: 入学登记 (预计1天)
├── 录入学生基本信息 [规划顾问] [高优先级]
├── 确认缴费信息 [管理员] [高优先级]
└── 分配规划顾问 [管理员] [高优先级]

阶段1: 选课指导 (预计1天) ⭐ 新增
├── 预约选课指导课 [规划顾问] [高优先级]
├── 进行选课指导 [规划顾问] [高优先级]
│   ├── 了解学生背景和目标
│   ├── 介绍课程体系
│   ├── 填写目标院校
│   └── 指导时间表填写
└── 确认指导完成 [规划顾问] [高优先级]

阶段2: 创建选课单 (预计2天)
├── 创建选课单 [规划顾问] [高优先级]
├── 添加目标院校 [规划顾问] [中优先级]
├── 规划课程明细 [全职导师] [高优先级]
└── 确认选课单 [规划顾问] [高优先级]

阶段3: 时间设置 (预计2天)
├── 填写学生时间表 [学生/规划顾问] [中优先级]
├── 设置导师时间表 [全职导师] [中优先级]
└── 确认时间匹配 [规划顾问] [中优先级]

阶段4: 排课安排 (预计1天)
├── 执行自动排课 [管理员] [高优先级]
├── 审核排课结果 [规划顾问] [高优先级]
└── 通知学生和导师 [规划顾问] [中优先级]

阶段5: 开始上课 (持续)
├── 开始第一节课 [全职导师] [高优先级]
├── 填写上课记录 [全职导师] [高优先级] ⭐ 新增
└── 确认学生签字 [学生] [中优先级] ⭐ 新增
```

### 5.2 新增工作流: 课程进度跟踪

```
工作流: course_progress (课程进度跟踪)

触发条件: 学生入学流程完成后自动创建

阶段1: 基础课程 (持续时间不定)
├── 基础课程排课 [规划顾问]
├── 按时上课 [导师/学生]
├── 完成课程 [导师]
└── 更新进度 [系统自动]

阶段2: 项目课程 (持续时间不定)
├── 项目规划 [全职导师]
├── 项目制作 [导师/学生]
├── 阶段评审 [全职导师]
└── 项目完成 [全职导师]

阶段3: 作品集打磨 (持续时间不定)
├── 作品集规划 [全职导师]
├── 作品打磨 [导师/学生]
├── 最终审核 [全职导师]
└── 作品集完成 [全职导师]
```

### 5.3 新增工作流: 申请跟踪流程

```
工作流: application_tracking (申请跟踪)

触发条件: 选课单确认后自动创建

阶段1: 院校准备 (申请季前)
├── 确定目标院校 [规划顾问]
├── 准备申请材料 [学生/规划顾问]
└── 确认材料完整 [规划顾问]

阶段2: 提交申请 (申请季)
├── 提交申请 [学生]
├── 确认提交成功 [规划顾问]
└── 跟踪申请状态 [规划顾问]

阶段3: 录取结果 (申请季后)
├── 收到录取通知 [学生]
├── 确认录取结果 [规划顾问]
├── 选择学校 [学生]
└── 更新学生状态 [规划顾问]
```

## 八、总结

当前工作流系统已实现基本框架，但存在以下核心问题：

1. **业务流程不完整** - 缺少选课指导、课程进度跟踪、申请跟踪
2. **角色映射不准确** - 规划顾问职责未体现
3. **与其他模块联动不足** - 缺少与上课记录、选课单进度的同步

建议按优先级逐步实施改进方案，确保工作流系统完全支撑业务需求。
