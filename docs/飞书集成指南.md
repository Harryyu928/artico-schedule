# 飞书集成指南

## 概述

ARTiCO系统已完整集成飞书开放平台，提供以下功能：

- **飞书登录** - 用户可通过飞书账号登录系统
- **消息通知** - 课程提醒、审批通知等自动推送到飞书
- **日历同步** - 课程安排自动同步到飞书日历
- **多维表格** - 学生、导师、课程、上课记录数据同步到飞书多维表格

## 一、飞书应用配置

### 1. 创建飞书应用

1. 访问 [飞书开放平台](https://open.feishu.cn/app)
2. 点击「创建企业自建应用」
3. 填写应用名称和描述
4. 记录 **App ID** 和 **App Secret**

### 2. 配置应用权限

在应用管理后台，开启以下权限：

| 权限名称 | 权限说明 |
|---------|---------|
| `contact:user.base:readonly` | 获取用户基本信息 |
| `message:im` | 发送消息 |
| `calendar:calendar` | 日历读写权限 |
| `bitable:bitable` | 多维表格读写权限 |
| `authen:user_info` | 获取用户身份信息 |

### 3. 配置重定向URL

在「安全设置」中添加重定向URL：
```
https://你的域名/api/auth/feishu/callback
```

### 4. 配置事件订阅

在「事件订阅」中配置：
```
https://你的域名/api/feishu/webhook
```

订阅以下事件：
- 消息接收 (`im.message.receive_v1`)
- 用户创建 (`contact.user.created_v3`)
- 用户更新 (`contact.user.updated_v3`)

## 二、环境变量配置

在系统中配置以下环境变量：

```bash
# 启用飞书集成
FEISHU_ENABLED=true

# 飞书应用凭证
FEISHU_APP_ID=cli_xxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxx

# 多维表格配置（可选）
FEISHU_APP_TOKEN=bascnxxxxxxxxxx
FEISHU_TABLE_STUDENTS=tbl_students
FEISHU_TABLE_TEACHERS=tbl_teachers
FEISHU_TABLE_COURSES=tbl_courses
FEISHU_TABLE_SCHEDULES=tbl_schedules
FEISHU_TABLE_CLASS_RECORDS=tbl_class_records
FEISHU_TABLE_CONSULTANTS=tbl_consultants

# 日历配置（可选）
FEISHU_CALENDAR_ID=ou_xxxxxxxxxxxx

# 事件加密（可选）
FEISHU_ENCRYPT_KEY=xxxxxxxxxxxxxxxx
FEISHU_VERIFICATION_TOKEN=xxxxxxxxxxxxxxxx
```

## 四、功能说明

### 1. 飞书登录

**访问地址**：`/api/auth/feishu`

用户点击飞书登录后：
1. 跳转到飞书授权页面
2. 用户确认授权
3. 系统获取用户信息
4. 自动匹配或创建用户账号
5. 完成登录

### 2. 消息通知

**API端点**：`POST /api/feishu/notify`

支持的通知类型：

| 类型 | 说明 |
|-----|------|
| `schedule_created` | 排课创建通知 |
| `schedule_updated` | 排课更新通知 |
| `schedule_cancelled` | 排课取消通知 |
| `course_reminder` | 课程提醒 |
| `approval_notification` | 审批通知 |
| `class_record` | 上课记录通知 |

**示例请求**：
```json
{
  "type": "schedule_created",
  "data": {
    "scheduleId": "xxx-xxx-xxx"
  }
}
```

### 3. 日历同步

课程安排创建或更新时，自动同步到飞书日历：
- 创建日历事件
- 邀请学生和导师参加
- 设置提醒（1小时前、1天前）

### 4. 多维表格同步

**API端点**：`POST /api/feishu/sync`

支持同步的数据类型：
- 学生数据
- 导师数据
- 课程数据
- 上课记录
- 选课单

**示例请求**：
```json
{
  "type": "students"
}
```

### 5. Webhook事件处理

**端点**：`/api/feishu/webhook`

处理飞书推送的事件：
- 消息接收：响应用户发送的指令
- 用户变更：同步用户信息
- 审批回调：处理审批结果

**支持的指令**：
- `帮助` / `help` - 查看帮助信息
- `课程` / `schedule` - 查看近期课程
- `进度` / `progress` - 查看学习进度

## 四、管理页面

## 五、常见问题

### Q1: 飞书登录失败怎么办？

检查以下几点：
1. 确认 FEISHU_ENABLED=true
2. 确认 App ID 和 App Secret 正确
3. 确认重定向URL配置正确
4. 查看浏览器控制台错误信息

### Q2: 消息发送失败？

1. 确认用户已绑定飞书账号
2. 确认应用有发送消息权限
3. 检查 openId 是否正确

### Q3: 日历同步失败？

1. 确认 FEISHU_CALENDAR_ID 已配置
2. 确认应用有日历权限
3. 确认用户在飞书中有日历权限

### Q4: 多维表格同步失败？

1. 确认 FEISHU_APP_TOKEN 已配置
2. 确认应用有多维表格权限
3. 确认表格ID配置正确

## 七、代码示例

### 发送排课通知

```typescript
import { feishuNotificationService } from '@/lib/feishu';

// 发送排课创建通知
await feishuNotificationService.sendScheduleCreatedNotification(
  studentOpenId,
  {
    courseName: '游戏设计基础',
    studentName: '张三',
    teacherName: '李老师',
    time: '2024-03-25 18:00-20:00',
    scheduleId: 'xxx-xxx-xxx',
  }
);
```

### 同步数据到多维表格

```typescript
import { feishuBitableService } from '@/lib/feishu';

// 同步单个学生
const result = await feishuBitableService.syncStudent(studentId);

// 同步所有学生
const result = await feishuBitableService.syncAllStudents();
```

### 同步到日历

```typescript
import { feishuCalendarService } from '@/lib/feishu';

// 同步课程安排到日历
const eventId = await feishuCalendarService.syncScheduleToCalendar(scheduleId);
```
