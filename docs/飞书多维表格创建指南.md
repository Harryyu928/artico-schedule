# 飞书多维表格创建指南

## 概述

本文档提供在飞书中创建新多维表格的详细步骤，用于 ARTiCO 自动排课系统的数据迁移。

## 创建步骤

### 1. 创建多维表格应用

1. 登录飞书，进入 **云文档** → **多维表格**
2. 点击 **新建多维表格** → **空白多维表格**
3. 命名为：**ARTiCO教务管理系统**

### 2. 创建数据表

按照以下顺序创建6张核心数据表：

## 3. 配置视图

为每个表创建以下视图：

1. **全部数据** - 显示所有记录
2. **待处理** - 筛选需要处理的记录（如未结课的上课记录）
3. **已归档** - 筛选已完成的记录

## 4. 配置自动化

在飞书多维表格中配置以下自动化规则：

1. **新学生创建时**：发送飞书消息通知顾问
2. **上课记录创建时**：发送飞书消息通知学生
3. **结课审核通过时**：更新导师结课数量

## 5. 获取表格信息

创建完成后，记录以下信息用于系统配置：

1. **App Token**：多维表格的 App Token
2. **Table IDs**：各数据表的 Table ID

获取方式：
1. 打开多维表格
2. 点击右上角 **...** → **API文档**
3. 复制 App Token
4. 各表的 Table ID 可在 URL 中查看

## 6. 配置系统

将获取的表格信息更新到系统环境变量：

```bash
FEISHU_BITABLE_APP_TOKEN=your_app_token
FEISHU_STUDENT_TABLE_ID=xxx
FEISHU_TEACHER_TABLE_ID=xxx
FEISHU_CLASS_RECORD_TABLE_ID=xxx
FEISHU_SELECTION_FORM_TABLE_ID=xxx
FEISHU_CONTRACT_TABLE_ID=xxx
FEISHU_CONSULTANT_TABLE_ID=xxx
```

## 注意事项

- 所有单选/多选字段的选项值必须与上述定义完全一致

- 日期字段格式建议使用 YYYY-MM-DD
- 创建时间/修改时间字段会自动填充
