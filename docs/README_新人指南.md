# ARTiCO 教务系统 - 新人上手指南

## 🚀 5分钟快速上手

### 第一步：打开系统

在浏览器地址栏输入：
```
https://a88dfcc3-0783-40eb-9263-db92a9462f7e.dev.coze.site
```

看到欢迎页面 = 成功打开！

### 第二步：切换角色体验

页面中间有5个彩色按钮，点击可以切换不同角色：

| 按钮 | 颜色 | 角色 | 你能看到什么 |
|------|------|------|-------------|
| 管理员 | 红色 | 顾问主管 | 所有数据、系统设置 |
| 规划顾问 | 蓝色 | 教务老师 | 签约学生、选课单 |
| 全职导师 | 绿色 | 全职老师 | 课程安排、学生进度 |
| 兼职导师 | 紫色 | 兼职老师 | 简化版课程信息 |
| 学生 | 橙色 | 学生 | 个人学习进度 |

### 第三步：看看功能入口

页面下方有4个快捷入口：

1. **学生时间表** - 学生填写每周可上课时间
2. **导师时间表** - 导师设置每周授课时间
3. **学生管理** - 查看所有学生列表
4. **导师管理** - 查看所有导师列表

## 🔧 维护工具

### 图形界面方式（推荐）

直接访问系统网页，看一眼就知道状态。

### 命令行方式

打开终端，输入以下命令：

```bash
# 检查系统状态（最常用）
/workspace/projects/scripts/maintenance.sh status

# 查看帮助
/workspace/projects/scripts/maintenance.sh help
```

## ❓ 常见问题

**Q: 网站打不开怎么办？**
A: 
1. 先刷新页面
2. 换个浏览器试试
3. 检查网络能不能上百度
4. 还不行就联系技术人员

**Q: 数据显示不对怎么办？**
A: 
1. 刷新页面
2. 截图保存
3. 联系技术人员
