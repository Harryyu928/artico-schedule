## 1. 系统概述

### 1.1 什么是 ARTiCO 教务管理系统？

ARTiCO 是一款专为艺术留学培训机构设计的**智能排课与教务管理系统**，帮助学生从入学到结课的全流程管理。

### 1.2 系统能做什么？

| 功能模块 | 说明 |
|---------|------|
| 学生管理 | 录入学生信息、跟踪学习进度 |
| 导师管理 | 管理导师信息、授课科目、可用时间 |
| 课程管理 | 维护课程库（基础课、项目课） |
| 选课单管理 | 规划学生的学习路径和课程安排 |
| 时间设置 | 设置导师和学生的可用时间段 |
| 自动排课 | 智能匹配学生和导师的时间，自动生成排课 |
| 上课记录 | 记录每节课的内容、学生表现、作业等 |
| 进度跟踪 | 实时查看学生的课程完成情况 |

### 1.3 核心理念

```
🎯 目标：帮助学生高效完成艺术留学作品集准备

📌 核心流程：
   入学咨询 → 创建选课单 → 设置时间 → 自动排课 → 上课记录 → 结课评估

🔄 迭代理念：
   每次上课都有记录，每个阶段都有评估，确保学习效果可追踪
```

## 8. 附录：术语表

| 术语 | 说明 |
|------|------|
| **选课单** | 学生整体学习规划的文档，包含所有计划学习的课程 |
| **选课单明细** | 选课单中每一门课程的具体信息，包括课时、进度等 |
| **排课** | 为学生安排具体的上课时间、导师和地点 |
| **上课记录** | 每次上课后的详细记录，包括内容、学生表现等 |
| **基础课** | 打基础阶段的课程，如游戏设计基础、美术基础等 |
| **项目课** | 完成完整项目的课程，如游戏设计项目、作品集项目等 |
| **作品集打磨** | 最后阶段的课程，帮助学生完善作品集 |
| **课时** | 学习时间的计量单位，通常1课时=1小时 |
| **专业方向** | 学生申请的专业方向，如游戏设计、动画等 |
| **目标国家** | 学生申请留学的国家，如美国、英国等 |
| **学习阶段** | 学生当前的学习阶段：基础/项目/作品集 |
| **项目阶段** | 项目课的具体阶段：Concept→Modeling→...→Portfolio |
| **时间槽** | 一天中可用的上课时间段，如10:00、15:00等 |
| **自动排课** | 系统根据学生和导师时间自动安排课程 |
