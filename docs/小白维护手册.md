## 日常检查

### 每天早上做这3件事

#### 第一步：打开网站看看能不能访问

1. 打开浏览器（Chrome、Edge 都可以）
2. 输入网址：`https://a88dfcc3-0783-40eb-9263-db92a9462f7e.dev.coze.site`
3. 看到页面正常显示 = ✅ 没问题
4. 显示"无法访问"或"错误" = ❌ 有问题，看下面的【紧急情况处理】

#### 第二步：切换角色看看仪表盘

1. 在首页点击任意角色按钮（如"管理员"）
2. 页面会刷新，显示对应的仪表盘
3. 看看数据是否正常显示

#### 第三步：检查有没有报错

**方法一：看页面**
- 如果页面上显示红色错误提示 = 有问题

**方法二：看日志（稍微技术一点）**
```bash
# 在终端运行这个命令
/workspace/projects/scripts/maintenance.sh logs error
```
- 显示"无错误日志" = ✅ 正常
- 显示一堆红色文字 = ❌ 有问题

## 常见问题处理

### 问题1：网站打不开

**症状：**
- 浏览器显示"无法访问此网站"
- 页面一直在转圈

**解决步骤：**
```
步骤1：刷新页面（按 F5 或点击刷新按钮）

步骤2：换个浏览器试试

步骤3：检查网络是否正常（能不能打开百度）

步骤4：如果还不行，联系技术人员
```

### 问题2：登录后显示空白

**症状：**
- 点击角色切换后页面空白
- 或者显示"加载中"很久

**解决步骤：**
```
步骤1：按 Ctrl+Shift+R 强制刷新页面

步骤2：清除浏览器缓存
- Chrome: 按 F12 → 点击 Network → 勾选 Disable cache
- 或者直接按 Ctrl+Shift+Delete 清除缓存

步骤3：重新打开网站
```

### 问题3：数据不对

**症状：**
- 学生数量显示不对
- 课程数量显示不对

**解决步骤：**
```
步骤1：刷新页面

步骤2：如果还是不对，记录下来：
- 应该是多少？
- 实际显示多少？
- 截图保存

步骤3：联系技术人员，把截图发过去
```

### 问题4：某个按钮点不了

**症状：**
- 点击按钮没反应
- 或者按钮是灰色的

**解决步骤：**
```
步骤1：看看按钮旁边有没有提示文字

步骤2：可能是权限问题
- 比如"学生"角色看不到"导师管理"
- 这是正常的！不同角色看到的功能不同

步骤3：切换到正确的角色再试试
```

## 紧急情况处理

### 🚨 情况1：网站完全无法访问

**立即做：**
1. 截图错误信息
2. 记录时间
3. 联系技术人员

**技术人员会做的事：**
```bash
# 检查服务状态
/workspace/projects/scripts/maintenance.sh status

# 如果服务挂了，重启
/workspace/projects/scripts/maintenance.sh restart
```

### 🚨 情况2：数据丢失或错误

**立即做：**
1. 不要刷新页面
2. 截图保存证据
3. 记录具体是什么数据出了问题
4. 联系技术人员

### 🚨 情况3：系统被攻击或异常访问

**立即做：**
1. 截图异常情况
2. 联系技术人员
3. 如果确认被攻击，可能需要暂时关闭系统

## 维护脚本使用说明

系统自带一个维护工具，就像一个"遥控器"，可以一键做很多事。

### 如何使用

打开终端（黑色的命令行窗口），输入以下命令：

```bash
# 查看所有可用命令
/workspace/projects/scripts/maintenance.sh help

# 检查系统是否正常运行
/workspace/projects/scripts/maintenance.sh status

# 查看今天的日志
/workspace/projects/scripts/maintenance.sh logs app

# 查看有没有错误
/workspace/projects/scripts/maintenance.sh logs error

# 重启系统（如果卡住了可以用）
/workspace/projects/scripts/maintenance.sh restart

# 查看系统信息
/workspace/projects/scripts/maintenance.sh info
```

### 命令对照表

| 命令 | 作用 | 就像... |
|------|------|---------|
| `status` | 检查系统活着没 | 给系统把脉 |
| `logs app` | 看今天发生了什么 | 看日记 |
| `logs error` | 看有没有出错 | 看错误报告 |
| `restart` | 重启系统 | 关机重启 |
| `info` | 看系统信息 | 看身份证 |
| `backup` | 备份数据 | 复印一份存档 |
