# 时间表输入流程设计文档

## 一、问题分析

### 当前问题
1. **学生时间输入时机不明确** - 不知道什么时候填、谁来填
2. **导师时间输入时机不明确** - 不知道什么时候填、如何更新
3. **排课依赖不清晰** - 自动排课前缺少时间表校验
4. **流程断层** - 选课单创建后无法确认学生/导师是否有可用时间

### 核心矛盾
自动排课需要：学生有时间表 + 导师有时间表 + 选课单已创建
但当前系统缺少触发时间表填写的业务节点。

## 二、优化方案

### 2.1 学生时间表输入流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      学生时间表输入流程                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │ 学生入学  │ ──→│ 顾问指导  │ ──→│ 填写时间表│ ──→│ 创建选课单│  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│       │               │               │               │        │
│       ▼               ▼               ▼               ▼        │
│   入学登记        预约指导课       学生自助填写      时间表必填   │
│   (顾问操作)      (顾问操作)       (学生操作)      (系统校验)   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 触发时机

| 阶段 | 触发者 | 操作 | 系统行为 |
|------|--------|------|----------|
| **入学登记** | 规划顾问 | 创建学生档案 | 创建空时间表模板 |
| **指导课预约** | 规划顾问 | 预约"选课指导"时间 | 自动预留该时间段 |
| **时间表填写** | 学生/顾问 | 填写周可用时间 | 保存到 time_availabilities |
| **创建选课单** | 规划顾问 | 创建选课单 | **校验时间表完整性** |

#### 学生时间表状态

```typescript
type TimeTableStatus = 
  | '未填写'     // 新生，需要顾问指导
  | '部分填写'   // 填写了部分时间段，不完整
  | '已填写'     // 填写了完整的周时间表
  | '待确认'     // 每周需学生确认本周时间
  | '已确认';    // 学生已确认本周时间
```

### 2.2 导师时间表输入流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      导师时间表输入流程                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │ 导师入职  │ ──→│ 填写时间表│ ──→│ 每周确认  │ ──→│ 临时调整  │  │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘  │
│       │               │               │               │        │
│       ▼               ▼               ▼               ▼        │
│   创建账号        填写固定时间      确认本周时间      请假/调课    │
│   (管理员)        (导师操作)        (导师操作)       (导师操作)   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 触发时机

| 阶段 | 触发者 | 操作 | 系统行为 |
|------|--------|------|----------|
| **入职** | 管理员 | 创建导师账号 | 创建空时间表模板 |
| **填写固定时间** | 导师 | 填写每周固定可用时间 | 设为默认模板 |
| **每周确认** | 导师 | 确认/调整本周时间 | 复制默认模板，允许修改 |
| **临时调整** | 导师 | 请假/临时加课 | 修改特定日期时间 |

#### 导师时间表模板机制

```typescript
// 导师时间表分为两层：
// 1. 默认模板（default_template）- 导师固定可用时间
// 2. 本周时间表（weekly_schedule）- 每周实际可用时间

interface TeacherTimeSchedule {
  teacherId: string;
  
  // 默认模板（每周自动复制）
  defaultTemplate: TimeSlotEntry[];
  
  // 本周时间表（可调整）
  weeklySchedule: {
    weekStart: Date;
    weekEnd: Date;
    slots: TimeSlotEntry[];
    confirmedAt?: Date;
  };
}
```

## 四、API 接口设计

### 4.1 学生时间表 API

```typescript
// GET /api/time-table/student/:studentId
// 获取学生时间表

// POST /api/time-table/student/:studentId
// 保存学生时间表
{
  slots: Array<{
    weekDay: WeekDay;
    timeSlot: TimeSlot;
    isAvailable: boolean;
  }>;
}

// POST /api/time-table/student/:studentId/confirm
// 学生确认本周时间表
```

### 4.2 导师时间表 API

```typescript
// GET /api/time-table/teacher/:teacherId
// 获取导师时间表（含默认模板和本周安排）

// POST /api/time-table/teacher/:teacherId/template
// 保存导师默认时间模板

// POST /api/time-table/teacher/:teacherId/weekly
// 保存/确认本周时间表

// POST /api/time-table/teacher/:teacherId/adjust
// 临时调整（请假/加课）
{
  date: string;
  timeSlot: TimeSlot;
  action: 'add' | 'remove';
  reason?: string;
}
```

### 4.3 排课前校验 API

```typescript
// POST /api/schedule/validate
// 排课前校验
{
  selectionFormId: string;
}

// Response
{
  valid: boolean;
  issues: Array<{
    type: 'student_time_missing' | 'teacher_time_missing' | 'no_match';
    message: string;
    studentId?: string;
    teacherId?: string;
  }>;
  warnings: Array<{
    type: 'partial_time' | 'limited_options';
    message: string;
  }>;
}
```

