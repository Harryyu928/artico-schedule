## 权限配置步骤

### 步骤1：开放权限配置

在[飞书开放平台](https://open.feishu.cn/app)找到你的应用，进入"权限管理"页面，添加以下权限：

#### 必需权限列表
| 权限名称 | 权限标识 | 用途 |
|---------|---------|------|
| 查看、评论、编辑和管理多维表格 | `bitable:app` | 创建记录 |
| 查看多维表格 | `bitable:app:readonly` | 读取表格结构 |
| 读取表格数据 | `base:table:read` | 读取数据 |
| 新增表格数据 | `base:table:write` | 写入数据 |
| 获取用户基本信息 | `contact:user.base:readonly` | 获取用户信息 |

### 步骤2：申请权限并发布版本

1. 添加权限后，点击"申请发布"
2. 填写版本说明（如：添加多维表格写入权限）
3. 等待管理员审批

### 步骤3：多维表格权限配置

1. 打开飞书多维表格：https://feishu.cn/base/HbztbPxc1a8wT8s47FIcgM9annc
2. 点击右上角「...」→「高级设置」→「权限」
3. 添加应用为协作者，赋予「可编辑」权限

## 重新执行导入

权限配置完成后，执行以下命令：

```bash
# 进入项目目录
cd ${COZE_WORKSPACE_PATH}

# 执行导入脚本
npx tsx scripts/feishu-import.ts
```

## 常见问题

### Q: 为什么返回"Forbidden"错误？
A: 应用没有多维表格写入权限，需要按上述步骤配置。

### Q: 导入需要多长时间？
A: 约6918条上课记录，每批500条，预计需要5-10分钟。

### Q: 可以只导入部分数据吗？
A: 可以，修改脚本中的batchSize或手动筛选数据。
